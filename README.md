## 哪些文件是什么用途

- `记忆与产物/`：统一记忆、训练流水、稳定知识、正式题库和历史归档。
- `口语训练内容/`：交给AI教师阅读的口语训练总上下文和执行手册；每日问答仍写入既有训练流水，不在这里重复建档。
- `项目集合/`：综合仪器、低功耗节点、电赛视觉与灰度的专题资料；旧顶层专题目录已迁移，后续按新位置读写。`lessons/`和`记忆与产物/04-微课/`仍保存跨项目课程页。
- `简历/`：原始证据、不可变母版、定制工具及已交付投递包；不能只因文件哈希相同就删除不同职责的母版/成品。
- `实习集合/`：各段实习资料的归集地。`实习-威思顿/`统一维护电表学习、实习讨论、专项训练及简历候选；`实习销售-仙女竹业/`是销售岗位简历任务线唯一存放地。正式技术简历母版和投递包仍按简历流程维护。
- `MISSION.md`、`NOTES.md`、`RESOURCES.md`、`learning-records/`：教学流程的辅助目标、偏好、来源与能力记录，不再复制当前进度。
- `tmp/sensor_before_20260825/`：有历史价值的改造前源码快照，**不是可清缓存，也不是当前源码**。
- C训练集`中间文件/题库源数据.json`及生成脚本、验证报告：正式数据源和证据，**不是可清缓存**。
- `.workspace-locks/`：短期协作锁；`维护工具/`：锁工具和文件级维护核验，不保存教学结论。

## 继续聊天前的三条底线

1. 其他聊天原有路径不变；不移动源码、课程、正式题库、简历工具或投递包。
2. 写入前按[AGENTS.md](AGENTS.md)领取分类锁，再重读、局部修改、复核并释放自己的锁；遇到他人的锁就停止该类别写入。
3. 只在唯一接续记忆里更新自己的任务段落。外部阅读副本按当轮授权同步；冻结的`project-together`不再维护。

最近一次维护的逐文件清理清单、重建方式与核验结果见[最近维护核验](维护工具/最近维护核验.json)。
