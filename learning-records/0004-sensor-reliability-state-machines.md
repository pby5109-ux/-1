# 传感器可靠性薄弱点转为状态机语义

用户已经理解失败数据不能覆盖有效值、DMA启动不等于发送完成，以及进入Stop前等待必须有超时；但对传感器Busy状态、BH1750连续转换，以及UART某一次BUSY请求是否被接受仍缺少稳定模型。

**Evidence:** 2026-08-25可靠性三链首轮回答中，用户认为AHT20 Busy仍可解析，把BH1750 `0x10`说成接收模式，并表示不理解UART BUSY场景；同时正确答出TX失败退出、Tx完成回调和Stop超时目的。

**Implications:** 下一轮不重复讲API名称，改用三条时间线训练：命令→转换中→数据就绪，配置连续模式→首帧等待→周期读取，以及调用被拒绝→再次调用→启动→完成回调。通过后再进入RTC Stop与300ms接收窗口的系统取舍。
