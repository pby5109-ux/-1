# 本岗位重点追问

1. **为什么采用分层架构？** 用综合平台BSP/GUI/TASK说明硬件接口、界面状态和任务编排各自负责什么；移植MCU时哪些接口保留、哪些时钟/引脚/中断配置需要改。模块分层不自动证明已经完成多芯片平台移植。
2. **如何管理共享缓冲？** 按当前简历说明缓冲的写入、发布、显示及释放状态；事件通知与数据所有权分开，ISR不能等待LCD释放缓冲。不要将设计或旧测试扩大为所有并发场景已验证。
3. **RTOS怎样传递数据与同步？** 队列承载数据，事件组表达可合并的状态位，信号量用于完成通知，互斥锁保护共享资源；讲出任务阻塞、优先级继承与ISR使用边界。
4. **怎样定位一次实际时序问题？** 用AWG低频定时参数或切频更新顺序：说明输入设置、实际输出、PSC/ARR和波表长度、参数更新顺序，以及修改后的验证，不只背外设名称。
5. **DMA完成是否等于通信成功？** 区分UART搬运/发送、模块空中发送、匹配ACK；说明CRC、节点/序号匹配、超时和有限重试，以及重复帧为何仍返回ACK。
6. **怎样测试协议模块？** 现有主机用例覆盖编解码、CRC异常、分包/粘包和重复帧；能够说明输入、预期结果和判定。主机测试不等于C固件、RF或量产验证。
7. **如何解释功耗和丢包率？** 54µA为既有用户报告实测，8个月是既定电池/上报工况下估算。丢包率本轮获用户确认，面试前补实际报文数量、距离/干扰、测试时长和重试口径；不扩展为任意环境保证。

技能边界：C为主语言，Python有现有项目使用；不添加C++熟练、CAN/Ethernet、AUTOSAR、Linux驱动、Yocto/Buildroot或量产流程经验。竞赛整机结果与本人视觉/灰度/交互贡献分开。无须因为岗位列出多类芯片或OS就声称全部掌握。
