# 青岛乾程科技 嵌入式软件工程师 — JD 摘录

> 摘录要点（非逐字原文）。用户 2026-09-29 提供于对话。

## 工作职责
1. 参与公司产品选型、软件设计、开发、调试及自测工作，确保软件开发按时保质的完成；
2. 参与嵌入式系统的底层驱动编程及调试；
3. 按照项目计划及要求，制定开发流程，跟进项目进度，解决产品在测试、生产和应用过程中软件相关的问题；
4. 根据部门能力提升等要求，制定、整理并规范技术文档；
5. 了解业务需求，前往现场调试或相关检测机构送检测试和进行问题排查，向客户提供技术支持。

## 任职资格
1. 本科及以上学历，电子、通信、电气、电力电子、自动化、控制、计算机相关专业；
2. 熟悉 C/C++ 语言，熟悉 Modbus、CAN、TCP/IP 等通信协议，熟悉 Linux 软件设计、开发；
3. 有一定的模拟和数字电路设计基础，了解单机（单片机）、DSP、ARM、FPGA 等嵌入式设计流程；
4. 熟悉 8/16/32 位的 MCU 程序设计，熟悉 IIC/SPI 等各种外围接口编程，对扩展 FLASH、SDRAM（有了解者优先）。
