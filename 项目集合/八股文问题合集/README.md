## 后续记录规则

- 每次技术问答后，把精简结论写入对应文件、对应分区，不按聊天时间连续堆到文件末尾。
- 同一问题的追问补充原题，重复内容合并；有新问题时在该分区新增三级标题。
- 通常每题保留 3～5 个要点，重点是核心结论、关键接口和易错点；必要时附一个短例子。
- 聊天解释可以详细，笔记不复制完整聊天；表格和示例只在帮助理解时保留。
- 新主题先归入现有大块，确实形成独立领域后再新增分区或文件，并更新此导航。
- 技术修正直接更新原条目；未经核实的字节数、芯片特性不写成固定结论。
