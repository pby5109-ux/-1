## 3. 十个教学模块

### 模块1：需求和系统边界

- 为什么低频短包、分布式部署适合LoRa。
- 为什么网关长期供电、节点重点低功耗。
- 为什么它与FreeRTOS智慧农场不重复。
- 已实现、已编译、已上板和未实测如何分开表述。

### 模块2：双构建与代码结构

```text
默认 Debug → BLE文本发送、5秒Stop
LoRaDebug → 二进制遥测、ACK/重试、正常30秒/异常10秒Stop
```

- CMake选项怎样控制功能路径。
- 协议层、节点传输层、应用层和PC网关各自职责。
- 为什么保留BLE默认构建而不是直接删除旧实现。

### 模块3：RTC Stop唤醒

```text
LSE → RTC计数器 → Alarm → EXTI17 → NVIC → CPU退出WFI
→ HSI临时运行 → 重建HSE/PLL 72MHz → 恢复SysTick
```

- Sleep/Stop/Standby差异。
- 为什么Stop不是“关闭CPU后程序重启”。
- 为什么醒后不恢复时钟会导致UART/I2C/SysTick时序错误。

### 模块4：整机功耗

- AHT20、BH1750、CH1116、雨滴板、LoRa模块和稳压器的状态。
- MCU Stop低不代表整板低。
- GPIO反向供电、外设断电后重初始化和上电稳定时间。
- 平均电流：`Iavg = Σ(Istate × tstate) / Tperiod`。

### 模块5：18字节协议

| 偏移 | 字段 | 长度 |
|---:|---|---:|
| 0 | Magic `A5 5A` | 2B |
| 2 | Version | 1B |
| 3 | Type | 1B |
| 4 | NodeID | 2B |
| 6 | Sequence | 2B |
| 8 | Flags | 1B |
| 9 | Temperature×10 | 2B |
| 11 | Humidity×10 | 2B |
| 13 | Light lux | 2B |
| 15 | Rain % | 1B |
| 16 | CRC16 | 2B |

- 大端序、结构体填充和定点数。
- valid位为何比只保留last-good更可靠。
- Seq如何识别丢包、重包和重试包。

### 模块6：CRC和网关代码

- CRC16-CCITT的输入、初值和多项式。
- 为什么CRC通过不等于业务值合理。
- Python网关怎样解析合法帧并生成11字节ACK。
- 测试向量如何约束C端和网关端格式一致。

### 模块7：LoRa基础

- LoRa物理层、厂商点对点透传和LoRaWAN的边界。
- BW、SF、CR、发射功率如何影响空中时间、灵敏度、碰撞和功耗。
- 为什么不能把SF和功率全部开到最大。

### 模块8：M0/M1/AUX与USART3

- 参考接线：PA8→M0、PA9→M1、PA1←AUX、PB10/PB11→UART。
- `AT+SWITCH=1`是一项模块预配置前提。
- M0/M1=`00`高时效，`11`休眠；AUX高表示忙，低表示完成。
- UART DMA完成、AUX完成、ACK成功分别证明哪一层。

### 模块9：ACK、超时和有限重试

- ACK必须匹配NodeID、Sequence、状态和CRC。
- 无ACK时最多重试一次，之后仍进入休眠。
- 为什么无限重试会让链路故障变成电池耗尽故障。
- 多节点时NodeID只解决归属，不解决空中碰撞。

### 模块10：故障树和面试答辩

- RTC不醒、醒后乱码、AUX一直高、DMA不回调、ACK超时、CRC错误、功耗高和距离不足。
- 回答结构：`现象→分层定位→可观察证据→修复→验证`。
- 90秒介绍、3分钟源码链路和三层随机追问。
