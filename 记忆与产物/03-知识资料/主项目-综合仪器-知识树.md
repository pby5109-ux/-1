## 六层知识树

### L1 项目全貌 —— 过关标准：不看资料 1-2 分钟讲完整

- 一句话定位：STM32F103RCT6 + FreeRTOS 的口袋综合仪器 = 示波器 + 万用表（DMM）+ 信号发生器（AWG）+ 可调稳压电源。
- 硬件组成：320×240 SPI LCD、6 按键、硬件比较器 + 电位器（触发）、DMM 挡位旋钮（GPIO 识别）、信号调理前端（÷2 衰减 + 1.25V 偏置，2.5V 基准）、运放 TLV9062、±2.5V 电荷泵电源域。
- 软件组成：三层（BSP → GUI → Task）；3 任务（LCD 栈 256/优先级 1，KEY 栈 128/优先级 2，LED 栈 128/优先级 1）+ 软定时器服务任务 + 空闲任务。以当前 `main.c` 为准，旧“全部优先级1”结论作废。
- 数据流总览：信号 → 调理 → ADC → DMA → ISR → 事件组/邮箱 → LCD 任务 → SPI DMA → 屏幕。
- 我的工作表述（面试版）：课程/工具提供 = CubeMX 初始化、lcd.a 图形库、教材整体设计；自己实现 = BSP/GUI/Task 层、One-Shot 模式。
- 训练形式：30 秒 / 1 分钟 / 3 分钟三档。

### L2 补充：原理图核对（2026-08-15初核；2026-09-21按Osc页器件值重算）

- **前端链**：耦合方式选择开关 → 衰减倍率选择开关（2MΩ 电阻网络）→ 同相跟随器 → 反相跟随器 → 增益挡位选择（总增益约×1或×10）→ 偏置分压 **(V+2.5)/2 → 0.25~2.25V**（即 V/2+1.25，与还原公式 ×2-2.5 对账一致）→ R17=1.5kΩ、C5=1nF低通 → PA1(ADC1_CH1)。该RC理论`fc=106.1kHz`，图中“100kHz”为近似标注。
- **输入耦合C4**：C4=22nF串联在AC挡，用于隔断输入直流分量、保留交流变化；DC挡旁路C4。若等效输入电阻约1MΩ，低截止约7.23Hz；若×10路径约10MΩ，约0.723Hz。实际值还取决于信号源阻抗、开关位置与寄生。
- **×10衰减补偿**：高臂`R1+R2+R3+R7+R10=9MΩ`，低臂`R20=1MΩ`，直流衰减1/10；低臂`C6||C7=165pF`，理想高臂补偿电容`C1=165pF/9≈18.33pF`，满足`9M×C1=1M×165pF`。C1为可调补偿电容，补偿过小方波圆边，过大出现过冲；寄生使实调值不一定恰为18.33pF。
- **保护与量程**：PESD24VL1BA用于接口浪涌/ESD保护，BAV99对后级节点进行钳位；图中文字给出极限±24V、工作范围±2.4V，仍以整机验证为准。
- **触发链**：主信号进入 **LM2903DR** 正端，U5电位器产生的阈值经R15=4.7kΩ、C2=4.7µF滤波后进入负端，比较器开集电极输出由R73=4.7kΩ上拉到3.3V，再到PA3 EXTI3。`fc≈7.20Hz`（忽略电位器等效电阻），电位器中点约4.70Hz；这是**触发阈值参考低通**，作用是减少阈值噪声和触发抖动，并非被测信号路径带宽。
- **电源去耦**：C3、C8～C14的100nF就近跨接各芯片电源与AGND，提供瞬态电流、旁路高频电源噪声并降低运放/比较器自激风险，不应当作主信号截止频率电容。
- **AWG 输出链**（第 3 页）：DAC PA4 → 电压跟随 → 移位+放大 `([0-2]-1)×2=[-2,+2]` → 160kHz LPF → 输出插座。
- **DMM 页**（第 5 页）：电压档 2/10/50V、欧姆档 1k/10k/100k/1M，双挡位开关 SK24D07VG4，LPF fc=15/16Hz，TLV9062。
- **电源页**（第 2 页）：MT3608B 升压 → AMS1117-3.3；LM27762 电荷泵 → ±2.5V。
- **板载未用资源**（第 7 页）：M24C64 EEPROM（I2C，PC10/PC11）、2.4kHz 有源蜂鸣器（PA15，Q2 驱动）——可讲"板载资源预留，未接入业务"。
- **波形区几何（用户再次实测，2026-08-17 定论；2026-09-02二进制实现复核）**：横向 **8 格 / 225px**，纵向 **6 格 / 157px**；平均每格约 **28.125px × 26.167px**。当前正式构建由`CMakeLists.txt`链接`APP/BSP/Inc/lcd.a`，没有编译`lcd_edu.c`。真实库X轴按时间映射：`一屏时间=8×XScale`，`每列样本数=SampleRate×8×XScale/225`，第x列从`XOffset+floor(x×每列样本数)`附近取到下一列边界。它不是把1024点逐点连成斜线，而是对每个像素列覆盖的样本求`min/max`并画一段竖线，以免降采样漏掉尖峰；像素缓冲按最多6列×157行×2B=1884B分块交给SPI DMA。1024是采集深度，不等于225个显示像素，当前配表多数挡位一屏约显示512个样本。反汇编还显示纵向换算约用`y=78-V×28.125/YScale`，与6格/157px得到的26.167px/格约有7.5%差异，需已知电压实测确认刻度误差。教学版`lcd_edu.c`仍是250×160、全部len压满X轴且用竖/水平阶梯线的简化模型，不得宣称与真实库等价。完整短课见`../../lessons/0005-oscilloscope-samples-to-pixels.html`。
- **奈奎斯特与混叠（2026-09-21）**：带限信号要唯一重建需`Fs>2fmax`，`Fs/2`为奈奎斯特频率；这只是数学防混叠下限，不等于两点/周期足以准确显示幅值和波形。500kSa/s对应250kHz，100kHz正弦为5点/周期；128kSa/s采100kHz会折叠为28kHz。方波还含奇次谐波，50kHz基波虽安全，但150kHz、250kHz等成分受约106kHz前端低通和采样边界影响，边沿会圆钝。ADC前模拟低通只能衰减带外成分；一阶106kHz滤波不能保证所有250kHz以上强信号都被彻底压制。

### L3 理解"为什么" —— 每个都要能讲出替代方案与取舍

1. 为什么事件组按需重绘，而不是定时全屏刷？（早期 100ms 全刷 → CPU 浪费 + 闪烁）
2. 为什么 ADC 用常规+注入双序列，而不是两个 ADC / 分时切换？（注入抢占常规，互不干扰）
3. 为什么采样用 TIM3 TRGO 硬件触发，而不是软件循环触发？（节拍精确、CPU 零参与）
4. 为什么触发用硬件比较器，而不是 ADC 采样后软件比较？（微秒级响应，画面稳定对齐）
5. 为什么 SPI 传输用 DMA + 信号量，而不是 HAL 轮询？（几 KB~几十 KB 数据，CPU 释放）
6. 为什么必须 VREFINT 校准？（ADC 是比例测量，VDDA 偏差 1% 全部测量偏 1%）
7. 为什么需要 Hold-Off 和强制触发？（防重复触发打断采集 / 防无触发黑屏）
8. 为什么 DAC 输出缓冲禁用？（后级运放驱动，内部缓冲引入失调/噪声）
9. 为什么 KEY 任务优先级 2，而 LCD/LED 为 1？（按键响应优先；KEY 每10ms扫描后主动阻塞，不会长期饿死低优先级任务；LCD/LED有各自阻塞点）
10. 为什么邮箱用 Overwrite/Peek 而不是 Send？（万用表只要最新值）
11. 为什么游标存百分比？（与屏幕分辨率解耦）
12. 为什么 1024 点而不是 1000？（2 的幂 + 采样深度惯例 + 225px 宽下平均每列约 4.55 点）

### L4 代码-硬件-数据流 —— 四条链路都要能脱稿画出来

1. **示波器链路**：信号 → 调理（÷2+1.25V）→ ADC 常规 CH1 ← TIM3 TRGO（采样率查表 ARR）→ DMA1_Ch1 1024 点 → `rawDataBuffer` → ADC 完成 ISR（×2-2.5 转电压）→ `waveform[]` → 事件组 bit7 → LCD 任务 → `LCD_DrawWaveform` → SPI DMA → 屏幕。触发侧：信号 → 比较器 vs 电位器 → EXTI3 上升沿 → 启动 DMA + 屏蔽 EXTI → 10ms Hold-Off 恢复。
2. **DMM 链路**：TIM2 10Hz → 注入序列 4 通道 → 注入完成 ISR → VREFINT 反推 VDDA → 挡位换算 → 邮箱 Overwrite → 事件组 bit0|bit1 → LCD 任务 Peek → 标签显示。
3. **AWG 链路**：波形表[1000] → DMA2_Ch3 循环 → DAC → PA4 → 运放 → ±2V 输出；改参数 → RestartDAC（停 TIM5→停 DMA→重算采样率→重建表→重启）。
4. **交互链路**：KEY 任务 10ms 扫描（表驱动）→ 消抖确认 → 回调改面板状态 + 置事件位 → LCD 任务按位重绘；Adjust 联动可一次置 3 位。

## 调试问题树（每棵按 现象→可能原因→排查顺序→高频根因 训练）

| 故障现象 | 排查链（从信号源往屏幕走） | 高频根因 |
|---|---|---|
| 完全无波形（黑波形区） | 信号源→调理前端→比较器/电位器→EXTI 触发→TIM3/ADC/DMA→事件组 bit7→LCD 重绘 | 强制触发定时器未启动 / EXTI 被 Hold-Off 误屏蔽 / DMA 长度不匹配 |
| 波形撕裂/闪烁 | 先排除 SPI（信号量同步正常）→ 定位到 `waveform[]` ISR 写/LCD 读竞争 → 双缓冲所有权/丢帧策略 | 无锁共享缓冲；只有指针切换但未防生产者覆盖DISPLAYING缓冲；互斥锁和`xEventGroupSync`均不能在ISR阻塞 |
| 白屏/花屏 | 电源→复位时序（Reset 1ms→125ms）→ SPI 配置（18MHz 模式0）→ DMA→INVOFF(0x20) 修正 | 复位时序不足 / INVOFF 未补发 / SPI 相位错 |
| 万用表读数不准 | VREFINT 采样时间（239.5 周期）→ VDDA 反推→挡位 GPIO 识别→换算公式 | VREFINT 采样时间不足 / 挡位识别错位 |
| 发生器频率错误 | 目标挡位→`AutoSampleRate()` 分支→ARR/PSC→重建波形表 | 低频分支（50/100/200Hz）未更新 ARR，恒 500Hz |
| 触发不工作/画面冻结 | 触发电平电位器→比较器输出→EXTI 配置→Hold-Off 状态→One-Shot 分支 | One-Shot 下 EXTI 保持禁用未重新武装 / 切模式未清挂起位 |
| 按键无响应 | 引脚上拉→扫描周期→消抖确认→回调注册→事件位置位→LCD 任务唤醒 | 回调未注册 / 置位用错 API（任务上下文用了 FromISR） |

## 当前分块学习复习卡：已经走过的链路（2026-09-27）

这张卡用于闭卷复述，不代表所有环节均已修复、编译或重新上板。当前新一轮分块学习已收束示波器和 DMM，信号发生器刚到首轮，电源尚未按本轮方法完整复盘。下文以当前唯一源码和正式构建为准；当前工作树有未提交修改。

### 1. 示波器：触发、采样、成帧、显示

被测信号经耦合/衰减、跟随、偏置与滤波后进入 ADC1 常规组；另一路与触发阈值比较，比较器输出边沿进入 PA3/EXTI3。EXTI 回调启动 ADC1 DMA 采集 1024 点并暂时屏蔽再次触发；TIM3 的 TRGO 提供逐点转换节拍，DMA1 Channel1 将 ADC 数据寄存器的转换结果写入 `rawDataBuffer[1024]`。ADC 一帧完成回调按当前公式 `V=(ADC码/4095×3.3)×2−2.5` 写入 `waveform[1024]`，再置位波形重绘事件。LCD 任务取事件位，`waveform_panel.c`把波形指针、采样率、时基和伏/格等参数交给正式链接的 `lcd.a` 绘图库，再经 SPI DMA 送屏。

正式构建链接 `APP/BSP/Inc/lcd.a`，**不编译**教学版 `lcd_edu.c`。既有库实现核对结论：按时间窗口把样本分配到约 225 个显示列，每列保留覆盖样本的最高/最低值并画竖线；采集深度 1024 不等于横向 225 个像素。`lcd_edu.c`的 250×160、逐点铺满 X 轴和阶梯连线只能作简化示例，不能当作正式程序。自动模式的 Hold-Off/强制触发与单次模式的重新武装决定下一帧何时允许开始。当前 `rawDataBuffer` 和 `waveform` 是前后两种数据，不是 A/B 双缓冲；下一次完成回调写 `waveform` 与 LCD 读同一数组有竞争风险。双缓冲＋状态机仍是讨论方案，未实施或验证。

一句话复述：**比较器决定从何时开始，TIM3 决定每点何时采，DMA 搬满一帧，完成回调换算并通知 LCD，绘图库把时间/电压映射成像素，SPI DMA 发屏。**

### 2. DMM：四项低速测量、校准、档位换算

TIM2 约 10Hz 更新事件触发 ADC1 注入序列：Rank1=CH9/PB1（万用表）、Rank2=VREFINT、Rank3=CH8/PB0（电源输出反馈）、Rank4=CH0/PA0（触发电平）。注入组完成回调读取四个结果，用 `VDDA=1.205×4095/Nref` 反推 ADC 参考供电；DMM 与电源的电压换算使用该 VDDA，当前触发电平换算则写死 3.3V。随后读取档位 GPIO，依 `if/else if` 的顺序选择 50V、10V、2V、10K、100K、1M；全部未命中时软件默认 1K，**不代表已证实物理开关确在 1K**。

电压档先用 `Vin=2×Vadc−2` 撤销前端缩放和偏置，再按 2V/10V/50V 档分别乘 1/5/25。电阻档按当前代码选择 `R0=200Ω/2kΩ/20kΩ/200kΩ`，固定并联校正电阻 `R1=1MΩ`；先算并联等效 `Rx=Vin×R0/(2.5−Vin)`，再算待测电阻 `R=R1×Rx/(R1−Rx)`。分母接近零或 `Rx≥R1` 时可能出现极大、非有限或负结果；当前未见边界保护，不能当作正常电阻显示。

回调将 `DMMData_t` **按值复制**到长度 1 的覆盖队列（邮箱），再置电源与 DMM 标签的重绘事件位。GUI 用 Peek 读取最新结构体，LCD 任务仅重绘相应区域。邮箱传**数据**，事件位传**哪些区域需要重绘**，两者都不负责锁住波形帧。

一句话复述：**TIM2 定期触发四项注入测量，VREFINT 校准 VDDA，GPIO 选档并还原测量值，邮箱保存最新一份结果，事件位通知 LCD 更新对应标签。**

### 3. 所有显示链共有的最后一段

LCD 任务等待事件位，按位选择波形、DMM、电源或其他面板的局部重绘。底层发屏先拉低 NSS，`HAL_SPI_Transmit_DMA` 启动传输；SPI 完成回调从 ISR 给二值信号量，等待中的发送函数恢复后拉高 NSS。**信号量表示这次 SPI DMA 发送完成，不等于整屏所有区域已绘完。** 当前发送函数未检查 DMA 启动返回值且无限期等信号量；若启动失败而回调不来，存在等待风险。这是源码风险，不是本轮实测故障。

### 4. 暂不算本轮学完的链路

信号发生器当前已找到“按键改形状/频率 → 重启流程重算采样率与波表 → TIM5 触发 DAC DMA 循环 → PA4 经模拟后级输出”的源码入口，但采样率边界、真实三角波与硬件触发条件仍待本轮闭卷复述。电源目前只核到 PB0/CH8 反馈码经 VDDA 与倍率换算后显示；模拟稳压/调节链需要继续对照原理图，不能把电压设定说成已确认由 MCU 软件控制。
