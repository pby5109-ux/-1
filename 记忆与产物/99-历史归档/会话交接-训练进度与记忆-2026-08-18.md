## 五、已纠正的关键事实清单（防重复踩坑，全部已核实源码/教材/实测）

### 波形项目（仪器）
1. **波形区几何：横向 8 格/225px、纵向 6 格/157px**（用户 2026-08-17 再次实测）。平均每格约 28.125px×26.167px；旧假设 250×160、25×20px/格作废。当前 `lcd_edu.c` 即使已改成 8×6，区域尺寸与像素换算仍不正确。
2. **采样率配表规律：64 点/格**（= 0.5×1024/(8格×XScale)）；`scale_panel.c` 的 `ARRs[]={143,143,143,143,225,561,1124,2251,5624,11249,22549,56249}`，前 4 档钳在 500kHz。
3. **实测：1kHz + 1ms/格 = 1 周期/格** → 标签与实际一致 → 真实库 lcd.a 的 X 轴是**时间映射**（用 SampleRate/XScale/XOffset），不是把 1024 点压满屏。由此：一帧 1024 点 = 16 格数据，8 格窗口只显示前 512 点，后半帧被裁剪（用户实测"无溢出"）。
4. **lcd_edu.c 三处错误**：① X 映射 `i/len×宽` 应为时间映射 ② X_DIVS=10 应为 8 ③ Y_DIVS=8 应为 6（游标换算连带错）。**修正前不得对面试官宣称"等价实现/项目使用我的库"**——正确表述："为了搞懂加密库接口写的教学重写，用实测反推发现了时间映射差异"。
5. 触发机制：比较器 **LM2903DR**（正端=信号，负端=电位器 MST22D18G2125 分压电平）→ 触发输出 → PA3 EXTI3。Hold-Off 10ms **单次**定时器在 t=0 触发时启动、t=10ms 到期回调里先清标志+清挂起再使能 EXTI；强制触发 100ms **周期**定时器在 Auto 下是**复位重新计时**（`xTimerResetFromISR`），只有 One-Shot 才 `xTimerStop`。强制触发实现 = `__HAL_GPIO_EXTI_GENERATE_SWIT`（软件置位触发事件）。
6. One-Shot 状态机：`ucRunMode`/`ucOneShotArmed`；防幽灵触发 = `WaveformCapture_SetRunMode` 里先 `CLEAR_FLAG`+`ClearPendingIRQ` 再 `EnableIRQ`；捕捉后 EXTI 保持禁用冻结波形；重新武装 = 切 Auto 再切回。
7. 前端信号链（原理图第 6 页）：耦合开关 → 衰减开关（2MΩ 网络）→ 同相跟随 → 增益挡位开关 → 偏置分压 **(V+2.5)/2 = V/2+1.25 → 0.25~2.25V** → 100kHz 抗混叠 LPF → PA1(ADC1_CH1)。极限 ±24V（BAV99+PESD24VL1BA 钳位）、工作 ±2.4V。触发路径滤波 fc≈8Hz。**偏置与衰减是同一环节（等阻分压取平均）**，不是先衰减后加 1.25。
8. ADC 常规序列 = 示波器 CH1/PA1，TIM3 TRGO 触发，DMA1_Ch1 **NORMAL** 模式 1024 半字 → `rawDataBuffer`；完成回调 `HAL_ADC_ConvCpltCallback` 里 1024 次 `(raw/4095×3.3)×2−2.5` 写入 `waveform[]` → `xEventGroupSetBitsFromISR(WAVEFORM_PANEL_REPAINT_BIT)` → `portYIELD_FROM_ISR`。**搬运是 DMA 干的，换算是 ISR 干的**（用户曾怀疑没有 DMA，已用源码证实）。
9. 注入序列 4 通道（TIM2 10Hz 触发，可抢占常规，约 80μs）：RANK_1=DMM 信号 PB1(IN9)、RANK_2=VREFINT 内部、RANK_3=电源输出 PB0(IN8) **×13 还原**、RANK_4=触发电平 PA0(IN0) 用 `÷4095×3.3×2−2.5`（**未校准**）。
10. **VREFINT 校准两步**：`VDDA真实 = 4095/N_ref × 1.205`（**4095 不是 4096**）；应用 `电压 = N/4095 × VDDA真实`。只用两处（DMM 值、电源读数）；**没用两处**（触发电平、波形还原，用 3.3 标称，可接受理由：触发/波形只关心相对）。`HAL_ADCEx_Calibration_Start` 是硬件自校准（校失调），与 VREFINT 软件校准是两层，勿混。
11. DMM 挡位：`DMM_GetRange()` 逐引脚读 `GPIO_PIN_SET`（50V→10V→2V→10K→100K→1M→**默认 1K**）。挡位是离散数字量，用 GPIO 不用 ADC。挡位换算：`fVin = fVadc×2−2`（DMM 前端 ÷2+1V 偏置，**与示波器 ×2−2.5 不同**）；电压 ×1/×5/×25；电阻 `Rx = fVin/(2.5−fVin)×R0`（R0 分档：200/2k/20k/200k）→ `X = R1×Rx/(R1−Rx)`（并联校正电阻已确认并同步为 **R1=1MΩ**；减号公式从并联等效反推实际待测电阻，修正对高阻更显著）。
12. 邮箱：`xQueueCreate(1, sizeof(DMMData_t))`；ISR `xQueueOverwriteFromISR`；LCD `xQueuePeek`（只读不取走）；**空邮箱 fallback**：`xDMMGetData` 返回"当前挡位 + 值 0"（上电首帧占位，显示层永不阻塞）。
13. `DMM.c` 末尾注释 `__HAL_ADC_ENABLE_IT(hadc, ADC_IT_JEOC)`：HAL 可能在首次注入回调后关 JEOC 中断——"万用表只刷一次就停"的第一排查点。
14. 绘制流水线（图层模型）：清区（背景）→ 网格（参考）→ 波形折线（数据：时间映射 X + `y=中线−V/YScale×每格实际像素` 的减号 + 越界裁剪）+ 触发虚线（标注）→ 游标（标注，百分比存储与分辨率解耦；X 读数 = pct×8格×XScale，Y = pct×3格×YScale）。实测网格 225×157，像素坐标应按总尺寸比例取整；同列画竖线/跨列画横线解决相邻点同列但 Y 跳变的断线。
15. 撕裂缺陷：`waveform[]` ISR 写/任务读，互斥锁被注释（`waveform_capture.c:7`）。互斥锁在 ISR 不可用（ISR 不能阻塞，等锁=死锁；mutex 无 FromISR 版本）。修法：双缓冲（访问者不重叠+指针单写原子，代价 4KB）或任务内转换（ISR 只置位，顺带消掉 ISR 内 0.3ms 浮点）。
16. 混叠：50kHz@30kHz 采样 → 样本序列与 10kHz 完全一致 → 软件无法区分；f假=|50k−2×30k|=10kHz（两步折叠：先 50−30=20 仍超奈奎斯特 15k，再折）；判据 = 换挡位时假波形频率跳变漂移。防线：100kHz 一阶 RC 抗混叠（只在最高采样档完全有效，低档有局限——可主动讲）。
17. 板载未用资源：M24C64 EEPROM（I2C，PC10/PC11）、2.4kHz 有源蜂鸣器（PA15，Q2 驱动）——"板载资源预留"。
18. AWG 输出链（第 3 页）：DAC PA4 → 电压跟随 → 移位+放大 `([0-2]-1)×2=[-2,+2]` → 160kHz LPF。电源页：MT3608B 升压 → AMS1117-3.3；LM27762 电荷泵 ±2.5V。
