AWG：什么存在哪里，谁先启动

本课只纠正三件事：波形表在RAM而非TIM5/DAC；本项目以500kHz作为保守上限；启动时先准备DAC DMA，最后启动TIM5触发源。

参数改变时的 RestartDAC

停 TIM5 → 停 DAC DMA → 计算采样率和波形长度、写 TIM5 PSC/ARR → 重建 RAM waveform[] → 启动 DAC DMA → 最后启动 TIM5。

对象保存/负责的内容不负责什么
RAM waveform[]一个周期的12位DAC数字码不产生采样节拍
TIM5PSC/ARR与TRGO更新节拍不保存整张波形表
DMA2 Channel 3按请求把RAM样本搬到DAC寄存器，循环工作不计算波形形状
DAC把数字码转换为PA4模拟电压不保存频率参数或整张表

连续输出链

TIM5 更新/TRGO → DAC触发并产生DMA数据需求 → DMA从RAM waveform[]搬下一个数字码 → DAC转换 → PA4模拟电压 → 电压跟随 → 移位/放大 → 幅度与模拟后级 → 约160kHz低通 → 输出端。

1000点与500kHz：三类证据

当前代码先令理想采样率为 frequency × 1000，默认每周期1000点。若超过代码设定的500kHz上限，就把采样率封顶到500kHz，并令 waveformLength ≈ 500000 / frequency。例如50kHz只剩约10点/周期。

  • 源码：AutoSampleRate把采样率硬封顶为500kHz。
  • 作者教材p9.2：称查芯片手册后最大采样率为500kHz。
  • ST官方DS5792表63：小码步进条件的最大更新率为1MS/s；满量程10位跳变建立时间典型3μs、最大4μs。

因此面试最稳妥的说法是：“本项目结合DAC动态建立时间与模拟后级带宽，把采样率保守限制为500kHz。”不要把不同码阶、精度和负载条件下的指标压缩成一个无条件绝对极限。

缺陷状态必须分开说

  • 已改、未编译/上板：ARR减1、频率变量先更新再调用、形状与频率调整各只重启一次。
  • 已确认、尚未修：UI称三角波，但当前公式只从约1V单调增加到约2V，实际是上升斜坡/锯齿。
  • 设计约束/待实测：高频时每周期点数减少，模拟低通又会衰减必要高频成分，可能产生阶梯、幅度下降和圆钝；需要示波器验证，不能说已经解决。
