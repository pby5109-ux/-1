怎样用 #if/#error 拦截未配置的采样频率？

我已作答 · 展开答案与口述思路

答案与解析

工程上通常概括为预处理→编译→汇编→链接。预处理展开宏、包含头文件、处理条件编译；编译进行语义和类型检查并生成汇编；汇编生成目标文件；链接合并目标文件/库、解析符号并重定位。 LIMIT 的定义合法，使用后展开为 3++，不满足自增操作数必须为可修改左值的要求，需要诊断。

#if !defined(SAMPLE_HZ) || SAMPLE_HZ <= 0
#error "SAMPLE_HZ must be positive"
#endif

#error 在所选条件分支中产生诊断。不能说 extern 只在链接阶段起作用：声明的类型、作用域和链接属性也在编译时处理。

口述思路

先讲四阶段，再把题中操作归位，最后说明诊断出现的阶段。

宏名不是变量；#define 本身合法不代表展开后的代码合法。# 在字符串/注释中不是指令；宏中的 #、## 也有别的用途。

C02 · A 必会

宏括号与重复求值

分别求 r、m 和执行后的 i，并说明如何安全替代。

#define SQUARE(x) x*x
#define MIN(a,b) ((a)<(b)?(a):(b))
int r = SQUARE(2+1);
int i = 1;
int m = MIN(i++, 5);

给所有参数加括号，能彻底消除宏风险吗？

我已作答 · 展开答案与口述思路

答案与解析

r=5，因为展开为 2+1*2+1。MIN 的条件先用 i 的旧值1再使 i=2；条件成立，选中分支又读取旧值2并使 i=3，因此 m=2、i=3。这一例两次自增有顺序，不是未定义行为，但违背“求最小值只消费一次参数”的直觉。

static inline int min_int(int a, int b) {
    return a < b ? a : b;
}

min_int(i++,5) 只消费一次 i++。((x)*(x)) 可修优先级，仍重复求值；SQUARE(i++) 会引入未排序的多次修改，不能给固定结果。

口述思路

先做文本展开→按运算顺序推导→指出括号解决什么、没解决什么→选类型明确的函数。

易错提醒

不要背成 MIN 中参数永远执行两次：条件必求值，只有选中的分支才再求值。

依据：C11 §6.5.15、§6.10.3。对应官方链接见使用说明的“技术核对入口”。

答案与解析

UL 必须跟在整数字面量后，不能跟在右括号后。可写：

           (c >= 'A' && c <= 'Z') || (c >= 'a' && c <= 'z');
