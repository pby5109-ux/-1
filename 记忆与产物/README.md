# 记忆与产物索引

`D:\APP\project_practice\codex-project`是所有学习资料的唯一维护工作区；早期`project-together`目录已经冻结，不再更新。本目录采用“一个动态记忆入口 + 一个训练流水账 + 若干单一职责资料”的结构。未来会话先读本页，再读`00-项目接续记忆.md`，并遵守根目录`AGENTS.md`的并发分类锁流程。

## 防止再次杂乱的规则

1. “现在做到哪里”只写在 `00-项目接续记忆.md`，其他文档只链接它。
2. 训练流水不复制进记忆文档；记忆文档只保存能力状态和下一断点。
3. 计划文件不保存长篇知识答案；知识资料不维护日期进度。
4. 功能相同才合并。历史记录、稳定复习材料和动态记忆用途不同，保留分开。
5. 旧事实被源码或实测推翻时，在动态记忆中写明“旧结论 → 新证据 → 当前结论”。
6. 每轮结束前按根目录 `AGENTS.md` 的清单更新并检查链接。
7. 多个对话可以并行读取，写入使用[分类锁工具](../维护工具/工作区锁.ps1)；取得锁后重读目标并核对哈希，只更新本轮所属任务段落，锁冲突时不得覆盖。
8. `project-together`只作旧资料核对；发现其中仍有价值的内容时，合并进本目录的对应唯一文件，不在旧目录继续维护。
9. 不凭目录名或修改时间判断可删。`tmp/sensor_before_20260825/`是保留快照；C专项题库JSON/生成脚本/验证报告是正式源与证据；简历母版与交付稿有不同职责。仅按`AGENTS.md`中的逐文件核验流程清理缓存。

## 记录为什么看起来仍是“昨天的文件”

- 动态记忆和训练流水采用**原文件持续更新**，不会每轮新建同名日期文件；应查看文件内容页首的“最后更新”和资源管理器的“修改时间”，而不是“创建时间”。
- 每轮当前结论覆盖写入`00-项目接续记忆.md`；低功耗节点完整问答写入[项目专属记录](../项目集合/低功耗项目理解产物/11-低功耗节点学习问答与题目索引.md)，其他项目仍写`02-训练记录/训练问答回顾.md`。
- 快速看已做题目与反复问题：低功耗节点打开上述项目专属记录，其他项目打开`02-训练记录/学习问题统计.md`。
- 若资源管理器仍显示旧时间，先按F5刷新，再确认打开的是`D:\APP\project_practice\codex-project\记忆与产物`而不是其他旧副本。
