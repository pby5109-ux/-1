2. 五路输入与位掩码

IN1 PB24 → bit4 IN2 PB20 → bit3 IN3 PA27 → bit2 IN4 PB19 → bit1 IN5 PB18 → bit0

DL_GPIO_readPins(port, pinMask)返回的是位掩码：低电平返回0，高电平返回该引脚对应的非零mask，不保证返回整数1。宏通过result == pinMask ? 1 : 0把它归一化。

4. 闭环控制链

五路GPIO → Get_Infrared_State()拼5bit → Track_err()得到位置误差/转弯标志 → position_pid(error, 0)得到修正量 → left = base - correction → right = base + correction → 电机差速让车回到黑线中心

正误差代表黑线偏向传感器左侧。若PID输出也为正，则右轮变快、左轮变慢，小车向左修正；负误差反之。

普通循迹PID与角度转弯不是同一控制器

  • 普通循迹：position_pid(error_huidu, 0)以灰度位置误差为输入，输出左右轮差速修正。修正量由误差、变化率和PID参数决定，并不天然只是小幅调整。
  • 当前转弯：识别转弯图样后保存yaw_now，使用固定左右轮速度主动旋转；Yaw相对变化达到约±70°时直接回到普通循迹。当前没有“达到70°后再执行角度PID缓慢调节”的阶段。
  • 可选改进：大角度阶段快速固定差速，接近目标时降速或使用角度PID，以targetYaw-currentYaw为误差；达到角度容差且重新检测到中心线后再切回灰度PID。

5. 约1ms控制节拍

80MHz / 8 / (255 + 1) = 39062.5Hz
(LOAD 38 → 39次计数) / 39062.5Hz = 0.9984ms

TIMA1的LOAD中断每约1ms执行一次，并调用datafun()。主循环负责按键和OLED；时间敏感的控制链在中断中运行。

6. switch、加权质心与混合分类

五路数字输入共有2^5 = 32种组合。当前switch的优点是能按赛道实测值手工标定误差，也能直接识别转弯图样；缺点是未列出的组合全部落入default，容易把未知状态误当作中心。

加权质心法可为五个探头赋位置权重，例如{+20,+7,0,-7,-20}，普通循迹时计算：

error = Σ(sensor[i] × weight[i]) / Σ(sensor[i])

它能连续处理更多组合，但不能独自判断所有场景：00000时分母为0，应判为丢线；11111的加权结果虽为0，却可能是交叉线而不是居中。因此本工程更适合“先分类、再算误差”的混合方案：

读取5bit状态 → 00000：TRACK_LOST → 转弯/宽线图样：TURN_LEFT、TURN_RIGHT或INTERSECTION → 普通图样：TRACK_NORMAL并用switch或加权法计算error → 只有TRACK_NORMAL进入位置PID；其他状态切换小车状态机

可让检测函数同时返回raw、mode、error，避免用一个error_flag混装“中心、丢线和未知状态”。再对32种输入逐项建立期望模式/误差表，可以在不上车时先验证分类逻辑。

7. 1ms中断预算如何验证

TIMA1约每0.9984ms进入一次ISR，因此一次ISR必须在下一次中断到来前完成，并预留明显余量。不能只看代码行数猜测：在ISR入口置高一个空闲调试GPIO，出口置低，用示波器或逻辑分析仪测高脉宽；高脉宽就是本次ISR执行时间，脉冲间隔应约为1ms。

若高脉宽达到或超过1ms，会造成中断连续占用、主循环OLED/按键长期得不到时间，控制周期也会失真。应把OLED、串口、复杂姿态解算等非紧急工作移出ISR；ISR只保留必要采样、快速控制输出和置标志。当前源码每1ms调用datafun()，每10次还调用姿态解算和测速，是否超预算必须实测，不能仅凭源码断言。

8. 两个必须主动指出的缺陷

  1. 四种转弯状态只置flag，没有给局部error赋值，随后读取并返回未初始化变量，属于未定义行为。
  2. error_flag = (error == 0)把正常居中、完全丢线和默认未识别状态混为一种语义，无法可靠区分“在中心”与“没找到线”。
