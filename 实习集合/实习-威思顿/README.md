## 维护方式

- 新讨论追加到同职责文件，不为每次聊天复制整套资料。
- 训练记录只写实际回答及纠错；“已经讲解”不能自动写为“已经掌握”。新分数仅在聊天里反馈。
- 手册事实、通用电工知识、假设演练、公司亲历分别标注；具体芯片与耦合电路需原理图支撑。
- 威思顿专题文件按knowledge锁维护；本目录README和资料归集按governance锁；主接续记忆按memory锁。正式技术简历母版和投递包仍遵守简历目录的既有维护流程。
