## 正向有功、电能与功率

常规参考方向下，电网向用户输送的有功电能记为正向有功电能，单位kWh。有功功率单位kW，是当时取用有功电能的快慢；电能是随时间累计的量。

教学例：稳定1kW负载工作1小时，消耗1kWh，即1度电。反向通常对应用户向电网送电；“反向”与“无功”不同，方向和电能性质是两个维度。该例未做实测。

## 三相四线与220/380V

四根线为L1/L2/L3/N。对称三相正弦电压相位相差120°，相线对N为相电压，两根相线之间为线电压。常见标称值为220/380V：

`U_AB = √(220² + 220² − 2×220×220×cos120°) = √3×220 ≈ 381V`。

上述220V是有效值，标称380V为取整表示。理想平衡正弦负载下N线电流为零；不平衡或某些谐波情况下可有中性线电流。PE保护接地线不计入三相四线中的四根线。

## RS485与电力线载波的数据路径

普通RS485典型路径：`MCU/UART → RS485收发器 → A/B双绞通信线 → 对端收发器 → 对端MCU`。A/B通信端子不是电网A/B相，不能直接接市电。

电力线载波典型路径：`数据 → 编码/调制 → 线路驱动 → 耦合与防护 → 电力线 → 接收耦合/滤波 → 解调/解码 → 数据`。载波解决传输问题；主动上报还是轮询由软件和协议机制决定。

存在专用调制、转换和耦合方案把串口或RS485来源的数据送上供电线路，不表示普通RS485接口自身能直接接L/N，也不证明本电表采用该方案。

## 耦合如何把高频送到电力线

耦合是信号在载波收发电路与电力线之间的传递。常见教学模型是驱动器驱动耦合变压器原边，副边通过耦合电容跨接L/N形成通信支路，配合滤波、调谐和防护。主负载电流不需要经过这个通信支路。

高频注入电流在线路的高频阻抗上形成通信电压。以线性简化模型表示：`V通信(f)=I注入(f)×Z线路(f)`。线路电感、电容和负载使其高频表现不同于50Hz；低通信频段阻抗或噪声可能衰减、干扰信号。

电容容抗：`X_C=1/(2πfC)`。以教学假设100nF计算：50Hz时约31.8kΩ，100kHz时约15.9Ω。利用频率选择性限制工频电流、传递通信频段；电容不是对交流高压的绝对阻断，安全隔离取决于完整设计。

变压器通过变化磁通把信号传到副边，按具体设计提供隔离或阻抗变换。接收侧耦合后仍需滤波、放大、解调和解码。普通接地示波器不得直接在未知市电侧用地夹测量。

信号叠加示例：`u线路(t)=311sin(2π50t)+1sin(2π100000t)`。表示约220V有效值的工频电压叠加1V峰值、100kHz通信示例。**不是将数据调制到50Hz，也不改变电网供电频率；100kHz、1V、100nF均不是威思顿产品参数。**

### 校验原理及纠错

1. 目的为比较电表计量值与参考值，不仅检查电压、电流看起来正常。典型脉冲法在同一计量区间，用被测表的脉冲数和表常数换算电能，再与参考电能比较。参考可能由校验仪内部标准测量提供，具体按仪器说明。
2. 表常数是脉冲与电能的换算关系。若C的单位为imp/kWh，则E表=N/C kWh。教学假设C=1000 imp/kWh，100个脉冲对应0.1kWh；不是本表实际常数。威思顿手册3.5节要求按铭牌确定常数。
3. 简化相对误差：ε=(E表−E参考)/E参考×100%。正值表示多计、负值表示少计；具体仪器符号约定及标准修正按说明，不能把屏幕实时刷新值均当独立完整测量。
4. 电压取样、电流钳、脉冲与RS485的职责不同。电流钳向校验仪提供参考测量用的电流信息；电能脉冲表示被测表累计电能。RS485用于通信读数或参数交互，不能仅因接了485就认为它是误差比较的核心或所有脉冲校验必须使用。
5. 三相电压、电流幅值正常不保证功率/电能正确；还需核对电压与电流的相别对应、电流钳方向、量程/变比及功率因数等。正弦条件下单相有功功率P=UIcosφ，因此错相或反向可能造成明显异常；此处是通用原理，不证明真实故障原因。
6. 三次平均值仅对同一条件下的重复测量有意义，三项原始误差及波动也要保留，不能用平均掩盖不稳定结果。教学例+0.12%、+0.10%、+0.11%，平均+0.11%。允许误差应按表等级、当前及适用负载条件、功率因数与测试依据确定，不根据B/C等级直接编造统一阈值。现场单个负载点结果不能等同整表所有项目合格，也不表示已调整计量系数。

### 模拟异常：校验仪电压取样连接不稳定

## 2026-10-04 校验基础三点讲解

用户回答摘要：表常数似乎从电表编码处看到，知道是出厂自带，不知道其含义；对参考电能及错相影响也表示不知道。当前只确认能回忆部分流程，不判为已理解校验原理，不给未作答题目评分。

1. **表号与表常数：**表号/编号用于识别设备；电能脉冲常数表示单位电能对应多少脉冲。常数通常标在铭牌，不能根据“编码”二字认定用户看到的具体字段。教学假设1000 imp/kWh：1000个脉冲对应1kWh，100个对应0.1kWh。仪器录入常数是为换算被测表电能，通常并不修改电表出厂常数。若实际1000却录成2000，同样100个脉冲会被换算为0.05kWh，产生人为比较偏差；非实际故障数据。
2. **参考电能：**对用户所描述的电压取样＋电流钳方案，典型校验仪用自己的测量通道同步采集电压/电流，计算瞬时有功功率并随时间累积得到参考电能；被测表另由脉冲换算电能。比较必须覆盖同一计量区间，参考测量链自身也有误差并需合适的准确度/校准状态。具体内部标准结构待仪器型号确认。用被测表自身显示的同源量代替独立参考，不能证明其准确度。依据见参考资料中Fluke校验原理文档。
3. **错相影响：**三相四线每相电压要与该相电流配对，三相有功功率累加后随时间累计电能。功率受电压、电流的相位关系影响，不只是两个幅值相乘；正弦条件下单相P=UIcosφ。用A相电压搭配B相电流会改变参与计算的相位关系，即使幅值看起来正常，计算功率仍可能错。仅作通用教学，不推断本表真实相位补偿实现。
